# 🚀 OpenStore: GitHub AI Explorer

*(English version below / Versión en inglés abajo)*

## 🇪🇸 Español

Plataforma inteligente impulsada por IA que transforma repositorios técnicos de GitHub en fichas comerciales fáciles de entender para usuarios sin conocimientos de programación.

![Vista de la Plataforma](./screenshot.png)

### ✨ Características Principales
* **Exploración Global:** Conexión directa con la API de GitHub para buscar repositorios y herramientas de código abierto.
* **Procesamiento con IA:** Utiliza la API de Google Gemini para leer documentación técnica compleja y extraer pitches comerciales en perfecto español.
* **Sincronización Automática:** Guarda los datos estructurados directamente en Google Sheets.
* **Prevención de Límites (Rate Limit):** Sistema de colas y fallbacks integrado para respetar las cuotas de la API gratuita.

### 🛠️ Stack Tecnológico
* **Frontend:** React, Tailwind CSS.
* **Backend:** Python, FastAPI.
* **IA & Datos:** Google Gemini API, Google Sheets API.

---

## 🇬🇧 English

An AI-powered platform that translates technical GitHub repositories into easy-to-understand commercial pitches for non-technical users.

![Platform View](./screenshot.png)

### ✨ Key Features
* **Global Exploration:** Direct connection with the GitHub API to search for open-source repositories and tools.
* **AI Processing:** Uses the Google Gemini API to read complex technical documentation and extract commercial pitches.
* **Automatic Synchronization:** Saves structured data directly to Google Sheets.
* **Rate Limit Prevention:** Integrated queue and fallback system to respect free API quotas.

### 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS.
* **Backend:** Python, FastAPI.
* **AI & Data:** Google Gemini API, Google Sheets API.
