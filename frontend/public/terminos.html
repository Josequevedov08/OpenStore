Terms & Conditions

Last updated: September 2026

1. What OpenStore is

OpenStore is a search tool that reads public GitHub repositories and uses an AI model (Google Gemini, or another provider the operator configures) to turn their technical README into a plain-language summary. It is a discovery and convenience tool — it does not own, host, or vet the repositories it displays.

2. AI-generated content can be wrong

Titles, descriptions, feature lists, and detected requirements are generated by an AI model reading a README automatically. They can be inaccurate, incomplete, or outdated. Always check the actual repository before relying on any of it for a decision.

3. Third-party repositories are not ours

Every repository shown belongs to its own author, under its own license, hosted on GitHub. We have no relationship with these authors and cannot vouch for the safety, quality, or maintenance of their code.

4. The "Install" / Smart Installer feature — read this

The Install buttons generate a script (.bat for Windows, .sh for macOS/Linux) that, when you run it yourself:

  • Downloads and installs missing tools (Git, Node.js, Python, etc.) using your system's own package manager (winget / Homebrew / apt / dnf / pacman), which may ask for administrator permission or your password.
  • Clones the actual, real source code of the third-party repository to your Desktop.
  • Installs that repository's dependencies and runs its start command.

This runs real third-party code on your computer. We validate the script we generate against obviously dangerous patterns, but we cannot audit the repository's own source code or its dependencies. Only use this feature for repositories from authors you trust. You are solely responsible for reviewing what you install and run.

1. Qué es OpenStore

OpenStore es una herramienta de búsqueda que lee repositorios públicos de GitHub y usa un modelo de IA (Google Gemini, u otro proveedor que configure quien opera el servicio) para convertir su README técnico en un resumen en lenguaje sencillo. Es una herramienta de descubrimiento y conveniencia — no es dueña, no aloja ni verifica los repositorios que muestra.

2. El contenido generado por IA puede tener errores

Títulos, descripciones, listas de características y requisitos detectados son generados por un modelo de IA que lee un README de forma automática. Pueden ser inexactos, incompletos o estar desactualizados. Siempre revisa el repositorio real antes de tomar una decisión basada en ellos.

3. Los repositorios de terceros no son nuestros

Cada repositorio mostrado pertenece a su propio autor, bajo su propia licencia, alojado en GitHub. No tenemos relación con esos autores y no podemos garantizar la seguridad, calidad o mantenimiento de su código.

4. La función "Instalar" / Instalador Inteligente — lee esto

Los botones de instalación generan un script (.bat para Windows, .sh para macOS/Linux) que, cuando tú mismo lo ejecutas:

  • Descarga e instala herramientas que falten (Git, Node.js, Python, etc.) usando el gestor de paquetes propio de tu sistema (winget / Homebrew / apt / dnf / pacman), que puede pedirte permisos de administrador o tu contraseña.
  • Clona el código fuente real del repositorio de un tercero a tu Escritorio.
  • Instala las dependencias de ese repositorio y ejecuta su comando de arranque.

Esto ejecuta código real de un tercero en tu computadora. Validamos el script que generamos contra patrones obviamente peligrosos, pero no podemos auditar el código fuente del repositorio ni sus dependencias. Usa esta función solo con repositorios de autores en los que confíes. Eres el único responsable de revisar lo que instalas y ejecutas.
