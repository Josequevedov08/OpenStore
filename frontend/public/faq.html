Frequently Asked Questions

Straight answers, no fine print buried elsewhere.

Why does a search take 15–30 seconds?
Each search finds up to 12 repositories, downloads each one's README, and sends it to an AI model to summarize — that's up to 12 real AI calls, run in parallel. It's not instant, but it should never take more than about a minute; if it does, something's wrong (see below).
I get "Couldn't reach the server" — what's happening?
This means the request failed or timed out. It usually resolves itself — try again in a moment. If it keeps happening, the AI provider's free-tier quota may be temporarily exhausted (shared across everyone using this instance) or the backend may be waking up from being idle (free hosting spins down after inactivity, the first request after that can take 30–50s just to wake up).
What does the "🤖 Analysis pending" badge mean?
The AI couldn't process that specific repository (quota, timeout, or a malformed response) — you're seeing GitHub's raw data (stars, language, description) instead of an AI-written pitch. It's an honest fallback, not a bug. Try searching again later.
Is OpenStore free to use?
Yes, for you as a visitor. Behind the scenes it runs on free tiers of GitHub's API and Google's Gemini API, which have shared usage limits — heavy use by many people at once can occasionally hit those limits.
Can I search private repositories?
No. OpenStore only searches and reads what GitHub's public API exposes — public repositories only.
What languages are supported?
The interface and the AI-generated pitches support English (default) and Spanish. The AI auto-translates from whatever language the original README is written in — Chinese, Russian, French, anything — into whichever of the two you pick.
Is the "Install" button safe?
It downloads a script you choose to run, which then clones and runs the real, actual code of a third-party repository. We sanitize the script itself against destructive patterns, but we can't audit the repository's own source code. See the visual manual and our Terms for the full picture — short version: only use it for repos from authors you trust.
Does OpenStore store my searches?
No accounts, no tracking, no database of your queries. See the Privacy Policy for the full breakdown of what's sent to GitHub's and Google's APIs to make a search work.
Something's broken or wrong — who do I tell?
Reach the project owner via GitHub.

Preguntas Frecuentes

Respuestas directas, sin letra pequeña escondida en otro lado.

¿Por qué una búsqueda tarda 15-30 segundos?
Cada búsqueda encuentra hasta 12 repositorios, descarga el README de cada uno, y lo envía a un modelo de IA para resumirlo — son hasta 12 llamadas reales a la IA, corriendo en paralelo. No es instantáneo, pero nunca debería tardar más de un minuto aproximadamente; si tarda más, algo falló (ver abajo).
Me sale "No se pudo contactar al servidor" — ¿qué pasa?
Significa que la petición falló o excedió el tiempo de espera. Normalmente se resuelve solo — intenta de nuevo en un momento. Si sigue pasando, puede ser que la cuota gratuita del proveedor de IA esté agotada temporalmente (la comparten todos los que usan esta instancia) o que el backend esté "despertando" tras estar inactivo (el hosting gratuito se apaga tras inactividad; la primera petición después de eso puede tardar 30-50s solo en despertar).
¿Qué significa el badge "🤖 Análisis pendiente"?
La IA no pudo procesar ese repositorio específico (cuota, timeout, o una respuesta mal formada) — estás viendo los datos crudos de GitHub (estrellas, lenguaje, descripción) en vez de una ficha escrita por IA. Es un respaldo honesto, no un error. Intenta buscar de nuevo más tarde.
¿OpenStore es gratis?
Sí, para ti como visitante. Por dentro corre sobre las capas gratuitas de la API de GitHub y la API de Gemini de Google, que tienen límites de uso compartidos — mucho uso simultáneo puede ocasionalmente topar con esos límites.
¿Puedo buscar repositorios privados?
No. OpenStore solo busca y lee lo que la API pública de GitHub expone — solo repositorios públicos.
¿Qué idiomas soporta?
La interfaz y las fichas generadas por IA soportan inglés (por defecto) y español. La IA traduce automáticamente desde el idioma original del README — chino, ruso, francés, cualquiera — al que elijas.
¿Es seguro el botón "Instalar"?
Descarga un script que tú decides ejecutar, que clona y corre el código real de un repositorio de terceros. Nosotros sanitizamos el script en sí contra patrones destructivos, pero no podemos auditar el código fuente propio del repositorio. Mira el manual visual y nuestros Términos para el panorama completo — resumen: úsalo solo con repos de autores en los que confíes.
¿OpenStore guarda mis búsquedas?
No hay cuentas, no hay rastreo, no hay base de datos de tus búsquedas. Mira la Política de Privacidad para el detalle completo de qué se envía a las APIs de GitHub y Google para que una búsqueda funcione.
Algo está roto o mal — ¿a quién le digo?
Contacta al dueño del proyecto vía GitHub.
