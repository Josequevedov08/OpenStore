How OpenStore works

A visual walkthrough — search, review, install.

1

Search

Type a keyword ("chatbot"), paste a repo URL, or use @username to browse someone's repos — it searches all of public GitHub.

2

Browse results

Each card is an AI-generated, plain-language summary of a real repository's README — stars, language, and a short pitch.

3

Open a card

See the full pitch, tech stack, key features, external requirements, and real GitHub stats (issues, forks, last commit).

4

Pick your OS

Click "Windows" or "Mac / Linux" to download a script built specifically for that repo — not a generic installer.

What the downloaded script actually does

Run it by double-clicking it. It works through these phases, in order, and stops to tell you before anything that needs your permission:

0. Warning — tells you it's about to run real third-party code, so you should trust the author first.
1. Checks Git is installed (where / command -v).
If missing → installs it with your system's own package manager (winget / Homebrew / apt / dnf) — you'll see a permission or password prompt from your OS, not from us.
2. Checks the runtime this specific repo needs (Node.js, Python, etc.) the same way.
3. Clones the repository to your Desktop (stops safely if a folder with that name already exists — it never overwrites anything).
4. Installs dependencies with the right command for that project (npm install, pip install -r requirements.txt, etc.).
5. Starts the project — or, if no safe start command could be detected, opens the folder and tells you to check its README.
Before you click Install: this genuinely runs code you didn't write, from a repository you may not know well. Only use it on repos from authors or organizations you trust — the AI-based checks stop the install script from doing anything destructive, but they can't audit the third-party project's own source code. See our Terms for the full disclaimer.

What if none of the first 12 convince you?

Each search brings 12 results at once, all visible on one screen (no page-flipping). To see more:

  • "Load more results" (at the bottom of the list) fetches the next batch from GitHub without losing what you've already seen.
  • "Top stars" / "Recently updated" changes the order: by popularity or by how recently the repo was last updated.
  • Your recent searches are saved (only in your own browser) so you can repeat them with one click.

Extra tools

All saved only in your own browser — no account needed, nothing sent to us.

Favorites

Click the bookmark on any card to save it, and browse them from the "Favorites" button in the header.

Compare

Check "Compare" on up to 3 cards to see stars, forks, issues, language, license, and stack side-by-side.

Filters

Narrow the current results by language, license, or "has an installer detected".

Light / dark theme

Toggle it from the header — your choice is remembered on this device.

Install history

Every installer you download gets logged — see it from the "History" button in the header.

Install as an app

OpenStore is a PWA — look for an install icon in your browser (or "Add to Home Screen" on mobile). Search still needs a connection; only the shell works offline.

Cómo funciona OpenStore

Un recorrido visual — buscar, revisar, instalar.

1

Busca

Escribe una palabra clave ("chatbot"), pega la URL de un repo, o usa @usuario para ver sus repos — busca en todo GitHub público.

2

Explora resultados

Cada tarjeta es un resumen en lenguaje sencillo, generado por IA, del README real de un repositorio — estrellas, lenguaje y una propuesta corta.

3

Abre una ficha

Mira la propuesta completa, stack tecnológico, características clave, requisitos externos y estadísticas reales de GitHub.

4

Elige tu sistema

Haz clic en "Windows" o "Mac / Linux" para descargar un script hecho específicamente para ese repo — no un instalador genérico.

Qué hace realmente el script descargado

Ejecútalo con doble clic. Avanza en estas fases, en orden, y se detiene a avisarte antes de cualquier cosa que necesite tu permiso:

0. Advertencia — te dice que va a ejecutar código real de un tercero, así que primero debes confiar en el autor.
1. Verifica que Git esté instalado (where / command -v).
Si falta → lo instala con el gestor de paquetes propio de tu sistema (winget / Homebrew / apt / dnf) — verás un aviso de permisos o contraseña de tu sistema operativo, no de nosotros.
2. Verifica el runtime que ese repo específico necesita (Node.js, Python, etc.) de la misma forma.
3. Clona el repositorio a tu Escritorio (se detiene de forma segura si ya existe una carpeta con ese nombre — nunca sobrescribe nada).
4. Instala dependencias con el comando correcto para ese proyecto (npm install, pip install -r requirements.txt, etc.).
5. Arranca el proyecto — o, si no se pudo detectar un comando de inicio seguro, abre la carpeta y te dice que revises su README.
Antes de hacer clic en Instalar: esto ejecuta de verdad código que tú no escribiste, de un repositorio que quizá no conoces bien. Úsalo solo con repos de autores u organizaciones en los que confíes — las validaciones basadas en IA evitan que el script de instalación haga algo destructivo, pero no pueden auditar el código fuente propio del proyecto de terceros. Consulta nuestros Términos para el descargo completo.

¿Y si ninguno de los 12 primeros me convence?

Cada búsqueda trae 12 resultados a la vez, todos visibles en una sola pantalla (sin pasar de página). Si quieres ver más:

  • "Cargar más resultados" (al final de la lista) trae la siguiente tanda de GitHub sin perder lo que ya viste.
  • "Más estrellas" / "Actualizados" cambia el orden: por popularidad o por qué tan reciente fue la última actualización.
  • Tus búsquedas recientes quedan guardadas (solo en tu navegador) para repetirlas con un clic.

Herramientas extra

Todo se guarda solo en tu propio navegador — no necesitas cuenta, nada nos llega a nosotros.

Favoritos

Haz clic en el marcador de cualquier tarjeta para guardarla, y navégalas desde el botón "Favoritos" del encabezado.

Comparar

Marca "Comparar" en hasta 3 tarjetas para ver estrellas, forks, issues, lenguaje, licencia y stack lado a lado.

Filtros

Acota los resultados actuales por lenguaje, licencia, o "tiene instalador detectado".

Tema claro / oscuro

Cámbialo desde el encabezado — tu elección se recuerda en este dispositivo.

Historial de instalación

Cada instalador que descargas queda registrado — míralo desde el botón "Historial" del encabezado.

Instalar como app

OpenStore es una PWA — busca el ícono de instalar en tu navegador (o "Agregar a pantalla de inicio" en móvil). Buscar sigue necesitando conexión; solo el cascarón funciona sin ella.
